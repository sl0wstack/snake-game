# Snake Game (C + SDL2)

A simple Snake game implemented in C using the SDL2 library for graphics and input handling.

## Features
- Real-time rendering using SDL2
- Keyboard-based movement controls
- Continuous game loop
- Collision detection (walls/self)
- Basic score tracking

## Tech Stack
- C
- SDL2

src/      -> Source code files
assets/   -> Images and sound effects

## How to Run

1. Install SDL2 on your system.
2. Compile the source files using gcc and link SDL2 libraries.
3. Run the generated executable.

(Example compilation may vary depending on your system setup.)

## Assets
Images and sound effects sourced from free online resources for educational use.

This project was built while learning SDL2 and practicing game loop implementation in C.
